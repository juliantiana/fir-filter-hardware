# FIR Filter Design and Hardware Implementation

This repository contains a course project on low-pass FIR filter design, fixed-point analysis, and SystemVerilog-based hardware implementation. It will include the filter-design workflow, architecture exploration, implementation results, and conclusions.

## Planned contents

- MATLAB or Octave scripts for coefficient design and frequency-response analysis
- SystemVerilog source and testbenches for baseline, pipelined, and parallel FIR architectures
- figures comparing original and quantized filter responses
- synthesis or FPGA implementation results such as area, timing, and power
- discussion of quantization, overflow handling, and architecture tradeoffs

## Repository layout

- `docs/` project writeups and architecture notes intended for GitHub readers
- `matlab/` filter-design and analysis scripts
- `verilog/` SystemVerilog RTL and testbenches
- `results/` plots, tables, and implementation reports
- `scripts/` helper scripts for data conversion and automation
- `assets/images/` diagrams and figures used in the documentation

## Status

Initial project scaffold. Content will be added as the design and hardware results are completed.
